 In this problem, you are given an integer `x`. A palindrome is a number that reads the same forwards and backwards. For example, 121, 5, and 1111 are palindromes, while 123 and 255 are not.

Your task is to write a function that checks if the given integer `x` is a palindrome or not. If it is a palindrome, the function should return `true`, and if it is not, it should return `false`.

To solve this problem, you can convert the integer `x` to a string, then compare the string with its reverse. If they are the same, then the number is a palindrome, otherwise, it is not.

Keep in mind that there might be some edge cases to consider, such as checking if the number has an odd length and handling leading zeros.
